# Advantage Online Shopping — QA & Test Automation Suite

A comprehensive Quality Assurance and Test Automation graduation project for the **Advantage Online Shopping (AOS)** platform covering Manual, Web UI, REST API, and Mobile (Android) testing.

## Scope & Features
- F01: User Registration & Account Management
- F02: Product Catalog & Search/Filtering
- F03: Product Details Page
- F04: Shopping Cart Management
- F05: Checkout & Billing/Shipping Flow
- F06: Payment Processing
- F07: Order History & Management

## Track Allocation
- `01-Manual-Testing`: Test plans, test cases, RTM, defect reporting.
- `02-Web-Automation`: Java + Selenium + TestNG + Page Object Model.
- `03-API-Testing`: REST Assured + Postman/Newman.
- `04-Mobile-Automation`: Python + Appium + PyTest.
- `05-Test-Reports`: Allure & Extent Execution Summaries.
- `06-Documentation`: System architecture, standards, risk analysis.
